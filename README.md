# Code Quality Assessment

Code Quality Assessment は、ソースコードの品質を複数の指標から定量的に計測・比較するためのツールです。

コードの複雑性や規模、保守性などを可視化し、実装の評価やリファクタリングの判断を支援することを目的としています。

## Features

- **Code Analysis**：ソースコードの複雑度や規模などを定量的に計測
- **Code Comparison**：異なる実装や変更前後の計測結果を比較
- **Report Generation**：計測結果をJSONやMarkdownなどの形式で出力
- **Extensibility**：計測指標や対応言語の追加に対応

## Usage

CLIから任意のソースコードを指定して計測・比較できるインターフェースを提供する予定です。

具体的なインストール方法やコマンドは、実装後に記載します。
