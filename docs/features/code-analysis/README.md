# Code Analysis

## Overview

Code Analysis は、ソースコードの規模や複雑度、保守性などを定量的に計測・比較するための機能です。

ソースコードの構造的な特性を可視化し、異なる実装の評価や、変更による影響の確認、リファクタリングの判断を支援します。

## Features

以下の機能を提供する予定です。

- **計測**：ファイルやディレクトリを対象に、コードの規模や複雑度などを計測
- **比較**：異なる実装や変更前後の計測結果について、指標ごとの差分を比較
- **出力**：計測・比較結果をJSONやMarkdownなどの形式で出力

計測結果は、関数・ファイル・プロジェクトなどの粒度で確認できることを目指します。

## Usage

CLIから解析対象を指定して利用することを想定しています。

- **単独計測**：指定したソースコードを解析し、各指標の計測結果を確認する
- **差分比較**：複数のソースコードを解析し、計測結果の差分や変化を確認する

具体的なコマンドやオプションは実装後に記載します。
