# Targets

## Overview

Code Analysisでは、解析対象としてファイルまたはディレクトリを指定できます。

指定された対象から対応するソースコードを選択し、静的解析を実行します。

## Supported Languages

以下のプログラミング言語に対応しています。

| Language | Extension |
|---|---|
| Python | `.py` |

## Target Selection

### File

単一のソースコードファイルを指定できます。

```bash
cqa analyze ./src/main.py
```

- 指定されたファイルを解析対象とします。
- 対応していない拡張子のファイルは解析できません。

### Directory

ディレクトリを指定し、配下のソースコードをまとめて解析できます。

```bash
cqa analyze ./src
```

- サブディレクトリを含め、再帰的にファイルを探索します。
- 対応言語のソースコードのみを解析対象とします。
- 対応していない拡張子のファイルは自動的に除外します。
- シンボリックリンクは追跡せず、解析対象から除外します。

## Exclusions

解析対象から特定のファイルやディレクトリを除外できます。

### Exclude Patterns

Glob形式のパターンを使用して除外対象を指定できます。

```bash
cqa analyze . --exclude "tests/**"
cqa analyze . --exclude "**/generated/*.py"
```

- 複数の除外条件を指定できます。
- 除外条件は解析対象ディレクトリからの相対パスを基準に評価します。
- `*` は単一のディレクトリ階層内の任意の文字列に一致します。
- `**` はゼロ階層以上のディレクトリに一致します。
- 除外対象のディレクトリ配下にあるファイルも解析対象から除外します。
- CLIとPython APIの両方で除外条件を指定できます。

### Git Ignore

`.gitignore` に基づく除外規則の適用を指定できます。

```bash
cqa analyze . --use-gitignore
```

- デフォルトでは `.gitignore` を参照しません。
- 有効にした場合、Gitのignore規則に従って解析対象を除外します。
- 親ディレクトリおよびサブディレクトリの `.gitignore` も考慮します。
- Git管理外のファイルも、除外規則に一致しない限り解析対象とします。
- 明示的な除外条件は、設定にかかわらず適用します。
- `.git/info/exclude` およびグローバルignore設定は対象外とします。

## Error Handling

解析対象の指定やファイルの解析に失敗した場合、以下の規則に従います。

### Error Types

| Condition | Error Code | Behavior |
|---|---|---|
| 指定したパスが存在しない | `TARGET_NOT_FOUND` | 解析を中断する |
| 指定したパスにアクセスできない | `TARGET_ACCESS_DENIED` | 解析を中断する |
| 対応していないファイルを直接指定した | `UNSUPPORTED_FILE_TYPE` | 解析を中断する |
| ソースコードに構文エラーがある | `SYNTAX_ERROR` | 対象ファイルの失敗を記録し、解析を継続する |
| 個別ファイルの読み込みに失敗した | `FILE_READ_ERROR` | 対象ファイルの失敗を記録し、解析を継続する |
| 解析対象が0件 | なし | 正常終了し、空の解析結果を返す |

エラー情報には、少なくとも以下を含めます。

- エラーコード
- エラーが発生した対象パス
- エラーの内容を示すメッセージ

### Fatal Errors

解析対象全体の処理を継続できないエラーが発生した場合、解析を中断します。

- CLIではエラーメッセージを表示し、非ゼロの終了コードを返します。
- Python APIでは例外を送出します。
- Python APIの利用者は例外の種類によってエラーを識別できます。

Python APIで使用する例外の種類は以下とします。

| Error Code | Python Exception |
|---|---|
| `TARGET_NOT_FOUND` | `FileNotFoundError` |
| `TARGET_ACCESS_DENIED` | `PermissionError` |
| `UNSUPPORTED_FILE_TYPE` | `ValueError` |

### Partial Failure

一部のファイルで解析に失敗した場合も、解析可能なファイルはすべて処理します。

- 成功したファイルの計測結果を保持します。
- 失敗したファイルとエラー情報を記録します。
- Python APIでは成功結果と失敗情報の両方を返します。
- CLIでは成功結果と失敗情報を出力し、非ゼロの終了コードを返します。

### Empty Targets

解析対象のファイルが0件の場合は正常な結果として扱います。

- 空の解析結果を返します。
- CLIでは解析対象のファイルが存在しない旨を表示します。
- CLIの終了コードは `0` とします。
- ファイル出力では解析対象が0件であることを表現します。

## Notes

- 解析対象のソースコードは実行しません。
- 計測する指標とその定義は[計測指標](metrics/README.md)を参照してください。
- 解析対象の指定方法は[利用方法](usage.md)を参照してください。
